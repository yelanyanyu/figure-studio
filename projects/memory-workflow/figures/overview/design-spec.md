# 设计规格

参考图为唯一设计依据，画布为 1986 × 1018，坐标保持 1:1，左到右阅读。详见 reconstruction-spec.json 与 qa 下的分区对象清单。

## 分区

1. init：x=38..413，y=34..1009，学习任务和三类虚线工作流簇。
2. cluster：x=470..1483，y=94..625，新增轨迹→Select→新簇/B；C 结构分区为 C1、C2。全部使用原生圆柱、文字和可编辑轨迹组合。
3. distill：x=470..1483，y=637..998，紫色云形区域、四个技能椭圆、蓝色虚线跨层连接。
4. inference：x=1546..1973，y=34..1009，查询、轨迹堆栈、技能卡片与 LLM/Env/Success 循环。

## 对象、样式与验收

Times New Roman，标题 37–41 px，步骤 26 px 加粗斜体，文字精确保留。蓝 #31589A，边框深蓝 #203864，轨迹绿 #009900；其余颜色依据参考。
轨迹图标分组，路径附着于本图标起止圆点。跨区域关系使用附着连接线，端点与标签避让。每区后保存当前结构审查与截图；必要修正后复查。最终保存实时快照，使用根目录 npm export 输出。

参考没有显微照片或其他必须保留的栅格场，本图计划零栅格图片。脑、地球、定位图标使用编辑轮廓及组合形状。
